# Repository instructions

## Pull requests

- Every PR must have a type label, such as `feat`, `fix`, `chore`, `infra`, or `docs`. Use the matching prefix in the PR title, for example `feat: add a Beginner opponent`.
- Keep PR descriptions short. Do not add extended PR descriptions or attribution trailers.
- Do not add `Co-authored-by` attribution to PR descriptions or commit bodies, including `Co-authored-by: Nicholas Nazario <nicholasnazario@Nicholass-MacBook-Pro.local>`.
